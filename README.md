# My Favorite Series: JoJo's Bizarre Adventure

## About the Series
**JoJo's Bizarre Adventure** commonly shortened to JoJo, it is an ongoing shonen and seinen manga written and illustrated by Hirohiko Araki since December 1986. The story spans nine parts, each following a different protagonist from the Joestar bloodline, with new settings and eras introduced in every part.
